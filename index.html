Selected work

What I build at Epoch AI / Zerg AI, and the firmware tooling I wrote before it. Some customer details are private.

  1. 2025 to now

    Zerg and ZTC

    Zerg is a spec-driven framework for autonomous coding agents, and ZTC is its terminal client. I built parallel tool dispatch so agents stop queueing behind each other, worktree-isolated batch execution so concurrent writers do not collide, and the live web interface where people watch a run as it happens.

    ZergChat and Zergboard are built on the same platform.

    Epoch AI / Zerg AI · ZTC in TypeScript and Rust, Zerg in Python

  2. 2025 to now

    Forward-deployed engineering

    For a customer’s organization-management and resource-planning platform, I built continual-validation harnesses that score agent output against deterministic checks of state, tools, artifacts, browser behavior and visual output.

    The checks catch regressions before changes are accepted.

    Epoch AI / Zerg AI · customer names withheld

  3. 2023 to 2025

    MOBIVOLT

    On a $5M+ DOD-funded fuel-cell program, I built the test-stand apps in C# and Avalonia, wrote a hardware-in-the-loop simulator so firmware could be exercised without a rig, and ported PIC32MZ firmware onto Harmony v3. I also handled migrations and used KiCad and ngspice for circuit work.

    50+ modules ported, 2,500+ lines of C tests, and 5 test stands kept running with zero downtime across 18 months.

    C#, .NET, Avalonia, Python, PyQt, C, KiCad, ngspice · defense program

Open-source contribution

A fix I found and sent upstream, merged on 5 August 2026.

mlx-audio decoder fix

I traced five differences between the MLX speech decoders and their PyTorch reference, layer by layer. Every Kokoro render had been 2.5 dB quiet, and the pitch path was one frame out of alignment. The fixes merged upstream.

On a 55-utterance check, MCD dropped from 7.29 to 4.09 dB.
