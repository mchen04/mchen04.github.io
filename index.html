Projects

Kestrel is my text-to-speech project. PHiLIP is an image-generation prototype I worked on with a team.

  • Kestrel

    distilled TTS for Apple Silicon · open weights

    I built Kestrel, a text-to-speech engine for making audiobooks on Apple Silicon.

    It renders speech quickly, but sounds less clear than Kokoro and does not meet its quality targets. The project page has the measurements and limits.

    Model card · Weights

    Kestrel: measurements, audit and upstream contribution

  • PHiLIP

    human-in-the-loop image generation on AMD ROCm

    Our PHiLIP prototype combines human feedback with image generation using AMD ROCm and PixArt-alpha. It won the AMD University Program Award in the AMD Pervasive AI Developer Contest.

    The current code has integration limits. I describe them on the project page.

    PHiLIP: prototype details and sources
