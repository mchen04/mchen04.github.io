    distilled TTS for Apple Silicon · open weights

    Final student-fast preset; model card evaluation dated August 1, 2026. Source-reported measurements, not a new benchmark.

    The final student-fast preset reports 4.97% mean duration drift and 50.30% worst-case drift on the frozen evaluation set. The worst case uses adversarial, punctuation-dense text. The weights page reports 0–8% on narration. Use the slower student preset when matching teacher durations matters.

    did not clear the reason this is the lead project

    Texture is audibly hazier than Kokoro under direct A/B. Mel-cepstral distortion comes in at 13.89 against a 3.98 pass bar, and speaker similarity at 0.981 mean, 0.874 worst, against a 0.998 gate. Both are failing gates.

  • PHiLIP

    human-in-the-loop image generation on AMD ROCm

    PHiLIP is a human-in-the-loop image-generation prototype built on AMD ROCm and PixArt-alpha. It won the AMD University Program Award in the AMD Pervasive AI Developer Contest.

    These are historical prototype timings. The current README documents route and configuration mismatches, plus machine-specific dependency paths. It does not verify model loading or end-to-end operation.
