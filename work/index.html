  • 2025 to now

    Zerg and ZTC

    Zerg is a spec-driven framework for autonomous coding agents, and ZTC is its terminal client. My work includes parallel tool dispatch so agents stop queueing behind each other, background sub-agents for work that outlives a single turn, worktree-isolated batch execution so concurrent writers do not collide, a sandboxed multi-agent workflow runtime, MCP and provider routing, and the live web interface. People can watch a run as it happens. I also cut the context a resumed session reloads by 92%.

    Epoch AI / Zerg AI · ZTC: TypeScript on Node, Rust native packages, React browser mirror · Zerg: Python core, Vue web IDE

  • 2025 to now

    Zergstack

    Zergstack is Zerg's internal deploy platform, a small Render for our Fly.io apps. I built its CI. GitHub Actions jobs run on each repository's own pool of Fly Sprites, and every Sprite resets to a clean checkpoint before each job. Jobs that need service containers go to one-shot Fly VMs. In test jobs, a Sprite job cost about a quarter of a GitHub-hosted one. I also moved sign-in to Zerg accounts and rebuilt the interface.

    Epoch AI / Zerg AI · TypeScript, Nuxt, PostgreSQL, Go CLI, Fly.io · internal tool, no public artifact

  • 2025 to now

    Multi-agent simulation engine

    A reusable simulation kernel in ZTC where AI agents act inside a shared world. It has typed LLM boundaries, agent memory, a causal world graph and deterministic replay. It runs Corporate Tycoon, 14 historical corporate crises where agents play the executives, and nine interactive worlds where you play one character while the world moves on its own. The simulation suite has 1,847 tests.

    Epoch AI / Zerg AI · TypeScript, PostgreSQL · experimental

  • 2025 to now

    Forward-deployed engineering

    I work with two customers whose names are private. For an aerospace company's organization-management and resource-planning platform, I built continual-validation harnesses that score agent output against deterministic checks of state, tools, artifacts, browser behavior and visual output. These checks catch regressions before changes are accepted. I also built an LLM and OCR invoice-extraction pipeline with no regressions across 22,643 documents, load-tested the platform to 1,000 concurrent users at about 100ms p95, and fixed 190+ defects. The other is an AI procurement intake and approval portal with grounded vendor research, approvals that stay owned by a human, and RBAC with separation-of-duties controls.

    Epoch AI / Zerg AI · customer names withheld, no public artifact

  • 2023 to now

    MOBIVOLT

    Part-time, on a $5M+ DOD-funded fuel-cell program. I built an AI-agent circuit design pipeline. From a six-line spec, it produced a fabrication-ready cell voltage monitor for 20 to 80-cell stacks in KiCad, checked with ngspice and enclosed in FreeCAD, with zero ERC/DRC errors and 36 of 36 simulation corners passing. I built 10+ automated test systems streaming 100+ sensor channels, then merged nine of their desktop apps into one cross-platform C# and Avalonia app that ran an 8-hour, 18-million-frame simulated soak without dropping a row. I migrated two fuel-cell controllers to Harmony v3 on PIC32MZ, 50 modules and 23K lines of C, with 3,900+ lines of C tests. I also built hardware-in-the-loop simulators, first in Python and PyQt and then in C#, so the firmware runs against plant models without a rig.

    C#, .NET, Avalonia, Python, PyQt, C, PIC32MZ, Harmony v3, KiCad, ngspice, FreeCAD · defense program, no public artifact
