My audiobook setup

I built Epub Listener, Hark and Kestrel to turn books into audio and listen on my device.

  • Epub Listener github

    Python CLI. EPUB in, chaptered MP3 out, via Edge-TTS, local Kokoro, Kestrel on Apple Silicon, any Hugging Face text-to-speech pipeline model, or any local command that writes audio. Checksum-based resume so a failed run does not start over. Embeds a timestamped read-along transcript, median word-onset error under 30ms.

  • Kestrel github

    My speech-generation engine. Its speed measurements, quality limits and independent audit are on the Kestrel project page.

  • Hark live (sign-in)

    Installable offline-first audiobook PWA. Import a chaptered MP3, or a PDF, EPUB, DOCX, text, Markdown or HTML file it narrates on the device with Kestrel through WebGPU, WASM where there is none. Everything is parsed and stored on-device, server sees metadata only. Karaoke-style read-along with sentence highlight and word-level marking. Playback and read-along work offline; only the first narration downloads the model, about 39MB of weights and a 24MB runtime.

Personal tools

Tools I use and experiment with.

  • tcd

    zsh and tmux helper that launches, finds, and reattaches long-running AI CLI sessions by partial name. tcd zer gets me back into the session for that repository without needing its full generated name.

    Sessions survive reboots and phone reconnects. I use it from my phone on the train, where matching a partial name is useful.

  • cs

    Rust CLI for macOS that swaps Claude Code accounts by replacing the Keychain entry in place, plus a per-profile usage dashboard.

    Account switching takes under a second, compared with the built-in logout and login flow. Each account keeps its own settings, and one master profile's skills, commands and agents are shared across them.

  • ESPN lineup bot

    Chrome extension plus a Node server that wakes five minutes before the first game each day and sets my fantasy basketball lineup off live injury reports. It uses the injury wire because projections can lag injury news by hours.

  • House by 30

    Offline-capable budgeting PWA that turns annual income, estimated taxes, payroll benefits, and planned expenses into a monthly budget.

    I built it for a friend and also use it myself. It requires sign-in.

  • Creator Harness

    A local content studio with writing review, media generation, restart recovery, and human approval steps.
