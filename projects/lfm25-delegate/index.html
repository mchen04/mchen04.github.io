LFM2.5-Audio Delegate

status
experimental, half-duplex
machine
M4 Mac mini, 24 GB
base
Liquid AI LFM2.5-Audio-1.5B
license
LFM Open License v1.0; commercial-use restrictions apply

My project adds learned delegation to Liquid AI's pretrained speech model on a 24 GB M4 Mac mini. A small adapter trained in the shared core teaches it to answer locally or request a stronger text model. Its existing audio head speaks both kinds of replies, including delegated answers that are still arriving. (Corrected model card (documentation commit 59c0adf); Liquid AI's pretrained base model; Retained E1 training configuration)

The release includes the adapter, runtime, configuration and recorded evaluations. A four-turn check used prerecorded input, real external-model responses and device playback. It doesn't establish live-human reliability. (R3 four-turn playback report; Pinned runnable release v0.9.1)

This is experimental half-duplex software with typed cancellation. Factual answers and room-microphone routing remain weak. Recent-answer context estimates what was spoken, and there is no live-human or human voice-quality validation. Audio processing is local, but delegation sends query and context text externally. It isn't production-ready. (Corrected model card (documentation commit 59c0adf); Acceptance criteria and retained failures; Runtime documentation)

Built on pretrained weights, not trained from scratch. License restrictions and reproduction limits apply. (LFM Open License v1.0; Unpublished reproduction evidence: October 5, 2026 reproduction check; installed dependencies and missing per-item judged results. Not independently rerun by Editor or Dot.)
