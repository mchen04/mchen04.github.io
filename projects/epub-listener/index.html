Epub Listener

Python CLI. EPUB in, chaptered MP3 out, via Edge-TTS, local Kokoro, Kestrel on Apple Silicon with a separate engine install, compatible Hugging Face text-to-speech pipeline models, or a local command that writes audio. Resume checks chapter text and narration settings before reusing audio. Embeds a timestamped read-along transcript. A historical Kokoro/Edge-TTS check reports median word-onset error below 30ms on isolated calibration words. Other backends can provide estimated sentence cues.
