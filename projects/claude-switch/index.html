cs

Rust CLI for macOS that swaps Claude Code accounts by replacing the Keychain entry in place, plus a per-profile usage dashboard.

Account switching takes under a second, compared with the built-in logout and login flow. Each account keeps its own settings, and one master profile's skills, commands and agents are shared across them.
